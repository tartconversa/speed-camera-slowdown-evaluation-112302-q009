# 资料契约

本目录只含本地合成记录，不包含真实驾驶员、车辆或道路资料。新闻报道描述的是厂商发布信息及公开说明，不是本资料集中的实测结论。

| 文件 | 字段 | 记录数 |
| --- | --- | ---: |
| `camera_catalog.csv` | `camera_id`, `road_id`, `direction`, `km_marker`, `limit_kph`, `map_version`, `valid_from`, `valid_to`, `review_state` | 35 |
| `trajectory_windows.csv` | `window_id`, `vehicle_id`, `road_id`, `direction`, `started_at`, `sample_rate_hz`, `traffic_state`, `weather` | 48 |
| `speed_samples.csv` | `window_id`, `offset_m`, `speed_kph`, `strategy_enabled`, `camera_seen`, `map_version` | 192 |
| `region_plans.csv` | `plan_id`, `region`, `road_id`, `direction`, `version`, `status`, `effective_from`, `receipt_id` | 21 |

输入文件之间通过明确的标识字段关联。记录时间均为 UTC 或 ISO 日期。缺失覆盖、待复核和撤回状态是有效业务事实，不能自动解释为零事件或成功。事件标签、回执、版本和授权范围以各行记录为准。所有示例数值由固定种子构造，仅供本地数据流程开发与测试。

## 字段取值

| 字段 | 取值 | 含义 |
| --- | --- | --- |
| `direction` | `N` / `S` / `E` / `W` | 道路通行方向；关联时方向必须一致 |
| `review_state` | `confirmed` / `needs-review` / `withdrawn` | 目录复核状态；只有 `confirmed` 可形成暴露 |
| `limit_kph` | 正整数 | 该条目的限速；同一范围多个条目限速不同时不做按限速推断 |
| `valid_from` / `valid_to` | ISO 日期 | 半开区间 `[valid_from, valid_to)`；`valid_to` 为空表示无明确截止 |
| `started_at` | 带时区 ISO 时间 | 实测为 UTC；无时区视为非法 |
| `sample_rate_hz` | 正数 | 轨迹采样频率；对照匹配要求一致 |
| `traffic_state` | `free` / `congested` / `incident` | `incident` 窗口不进入常态效应结论 |
| `strategy_enabled` / `camera_seen` | `yes` / `no` | 策略是否启用、车辆是否实际识别到摄像头 |
| `status` | `accepted` / `partial` / `proposed` / `withdrawn` | 计划状态；`proposed` 不生效，`withdrawn` 表示撤回 |
| `map_version` | 字符串 | 地图版本；目录条目与速度样本必须一致才可关联 |
| `receipt_id` | 字符串 | 决策回执标识，用于追溯 |

## 关联与计数规则

- **主键**：`camera_id`、`window_id`、`plan_id` 必须唯一；重复行保留首次并报告。
- **样本键**：`(window_id, offset_m)` 唯一；重复样本保留首次并报告。
- **引用完整性**：速度样本必须引用存在的窗口；孤儿样本不参与分析并报告。
- **曝光单位是窗口**，不是目录条目。同一道路/方向/地图版本下的多个确认条目
  仍只让一次经过算一次暴露。
- **目录记录不代表实际启用**：窗口内没有 `camera_seen=yes` 时记为
  `camera_not_observed`，不形成暴露。
- **方向不一致**：只有对向确认条目的窗口记为 `direction_mismatch`，不使用对向
  条目凑数。目录方向本身可能有误，这只能作为待复核信号。
- **地图版本不一致**：目录条目与样本地图版本不符时记为 `map_version_mismatch`。
- **窗口内一致性**：同一窗口混用不同 `strategy_enabled` 或不同 `map_version`
  时，该窗口不进入比较。

## 保留与更正

- 历史行程记录保持原始 `map_version` 与 `strategy_enabled`，不随目录更正重写。
- 计划记录不可变；撤回通过追加 `status=withdrawn` 的新版本表达，旧版本保留。
- 目录条目被移除、撤回、改限速或改方向时，相关生效范围进入重新审查清单。
- `proposed` 范围不属于已验证范围，不能据此扩大启用。
