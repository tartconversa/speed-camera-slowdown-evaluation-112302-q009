# 资料契约

本目录只含本地合成记录，不包含真实驾驶员、车辆或道路资料。新闻报道描述的是厂商发布信息及公开说明，不是本资料集中的实测结论。

| 文件 | 字段 | 记录数 |
| --- | --- | ---: |
| `camera_catalog.csv` | `camera_id`, `road_id`, `direction`, `km_marker`, `limit_kph`, `map_version`, `valid_from`, `valid_to`, `review_state` | 35 |
| `trajectory_windows.csv` | `window_id`, `vehicle_id`, `road_id`, `direction`, `started_at`, `sample_rate_hz`, `traffic_state`, `weather` | 48 |
| `speed_samples.csv` | `window_id`, `offset_m`, `speed_kph`, `strategy_enabled`, `camera_seen`, `map_version` | 192 |
| `region_plans.csv` | `plan_id`, `region`, `road_id`, `direction`, `version`, `status`, `effective_from`, `receipt_id` | 21 |

输入文件之间通过明确的标识字段关联。记录时间均为 UTC 或 ISO 日期。缺失覆盖、待复核和撤回状态是有效业务事实，不能自动解释为零事件或成功。事件标签、回执、版本和授权范围以各行记录为准。所有示例数值由固定种子构造，仅供本地数据流程开发与测试。
